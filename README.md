# Automatización de Datos

Repositorio público de **documentación, arquitectura y andamiaje** para herramientas de automatización de datos.

## Estado real auditado

**Estado:** andamiaje/documentación; no es un producto de software verificable todavía.

La rama main contiene documentación, configuración, flujos de CI/CD y material de arquitectura, pero la auditoría del árbol Git actual **no encontró el directorio tools/, paquetes de las tres herramientas ni suites de pruebas** que la documentación histórica describe.

Por tanto, no se declara que las herramientas estén implementadas, testeadas o listas para producción.

### Componentes previstos

| Componente | Estado actual |
|---|---|
| data-processor | Especificado/documentado; implementación no presente en main |
| pdf-to-excel | Especificado/documentado; implementación no presente en main |
| file-converter | Especificado/documentado; implementación no presente en main |

| GitHub Pages | Presente |

## Fuente de verdad

La autoridad transversal de gobernanza es Directivas-de-Seguridad.

Este repositorio público no contiene datos de clientes, secretos ni credenciales.

## Criterio para declarar una herramienta implementada

Una herramienta solo podrá pasar a **IMPLEMENTADA** cuando exista código versionado, pruebas relevantes, validación reproducible y evidencia registrada. La documentación por sí sola no cambia el estado.
