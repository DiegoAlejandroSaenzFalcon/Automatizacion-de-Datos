# Automatización de Datos — Documentación y andamiaje

Repositorio público de **documentación, arquitectura y andamiaje** para futuras herramientas de automatización de datos.

## Estado real auditado

**Estado:** documentación y andamiaje; no se declara implementación de software en la rama `main`.

La documentación describe tres herramientas previstas:

| Componente | Estado actual |
|---|---|
| data-processor | Especificado/documentado; implementación no presente en `main` |
| pdf-to-excel | Especificado/documentado; implementación no presente en `main` |
| file-converter | Especificado/documentado; implementación no presente en `main` |
| Documentación MkDocs | Presente |
| Validación documental CI | Presente |
| GitHub Pages | Configurado |

Los ejemplos de instalación, CLI y pruebas que aparecen en las páginas técnicas son **especificaciones/documentación histórica** y no constituyen evidencia de que esos paquetes existan actualmente.

## Fuente de verdad

La autoridad transversal de gobernanza es **Directivas-de-Seguridad**.

Este repositorio público no debe contener datos de clientes, secretos ni credenciales.

## Criterio de implementación

Una herramienta solo podrá pasar a **IMPLEMENTADA** cuando exista código versionado, pruebas relevantes, validación reproducible y evidencia registrada. La documentación por sí sola no cambia el estado.

## Documentación

La documentación vive en `docs/` y se publica mediante MkDocs/GitHub Pages. Las páginas de referencia de herramientas se conservan como especificaciones para futuras implementaciones.
