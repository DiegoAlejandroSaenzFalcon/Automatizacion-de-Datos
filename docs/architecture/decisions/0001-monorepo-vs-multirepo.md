# ADR 0001: Monorepositorio frente a múltiples repositorios

**Estado:** Requiere revisión histórica

**Fecha original:** 2025-09-06

**Autor:** Diego Alejandro Sáenz Falcón

## Contexto

El documento histórico describe una decisión de agrupar varias herramientas en un monorepositorio.

## Estado auditado

La estructura descrita por este ADR no coincide actualmente con la rama main: el directorio tools/ no está presente.

Por tanto, los pasos marcados históricamente como completados no deben interpretarse como evidencia de que la implementación exista hoy.

## Decisión vigente

Este ADR se conserva como registro histórico. La decisión de reconstruir las herramientas, mantener este repositorio como andamiaje o separar componentes debe documentarse en un ADR posterior cuando exista evidencia y una decisión explícita.

## Criterio

La documentación histórica no es fuente suficiente para declarar una migración o implementación como completada.
